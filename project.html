Database Project : การวิเคราะห์ออกแบบฐานข้อมูลนิตยาไก่ย่าง

  • โครงงานนี้เป็นส่วนหนึ่งในการศึกษารายวิชา ITDS221 Database Management System ซึ่งกลุ่มของนักศึกษาได้นำธุรกิจ "นิตยาไก่ย่าง" มาศึกษาและวิเคราะห์ฐานข้อมูลที่ควรมี
  • จากการทำโครงงาน นักศึกษาได้ฝึกคิดในเรื่อง Business Process Analysis, Business Rules, การออกแบบแผนภาพ ERD, Relational Schema ตลอดจน การสร้าง Data dictionary ที่จะนำไปสู่การสร้างฐานข้อมูลต่อ
  • นักศึกษาได้เป็นผู้รับผิดชอบในหัวข้อ กระบวนการการจัดซื้อและบริหารห่วงโซ่อุปทาน (Procurement & Supply Chain Management)
  • ทำให้นักศึกษาได้ทักษะออกแบบฐานข้อมูลเมื่อได้รับ requirement จากลูกค้า

Software Engineering Project : Ananta Airport Management

  • โครงงานนี้เป็นส่วนหนึ่งในการศึกษารายวิชา ITDS262 Software Engineering Lab โดย requirement คือ การออกแบบระบบบริหารจัดการการดําเนินงานสนามบิน
  • นักศึกษาได้ฝึกฝนตั้งแต่เรื่องการคิด Functional และ Non-functional Requirement, การออกแบบ Usecase Diagram, Data Flow Diagram
  • ระหว่างการดำเนินงาน พบปัญหา คือ เมื่อออกแบบ Data Flow Levels ที่สูงขึ้น เนื้อหาละเอียดขึ้น ทำให้ต้องย้อนกลับไปแก้ Usecase Diagram และ Context Diagram ซึ่งทำให้เรียนรู้ว่า เมื่อออกแบบจะต้องคิดให้ละเอียด และต้องย้อนกลับมาเช็คเสมอก่อนนที่จะดำเนินการต่อไปยังขั้นถัดไป
  • โครงงานนี้ยังไม่เสร็จสมบูรณ์ อยู่ระหว่างดำเนินการสร้าง Mock-up Prototype และ Test cases

Web Application Project : ก้องคนดีมี "PET FOOD"

  • โครงงานนี้เป็นส่วนหนึ่งในการศึกษารายวิชา ITDS242 Web Application Lab โดยกลุ่มของนักศึกษาได้เลือกจัดทำเว็ปไซต์ขายอาหารสำหรับสัตว์เลี้ยง
  • นักศึกษาได้เป็นหนึ่งที่รับผิดชอบในหัวข้อของ Database ได้แก่ ERD, Relational Schema และ Data Dictionary
  • โครงงานนี้ยังไม่เสร็จสมบูรณ์ อยู่ระหว่างดำเนินสร้างเว็ปไซต์ (Front-End และ Back-End)
